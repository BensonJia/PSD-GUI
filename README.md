# PowerSimulationDynamics-GUI

这是一个基于 PySide6 和 NodeGraphQt 的桌面应用，用来查看和编辑
`PowerSimulationsDynamics.export_network` 导出的项目目录。

它提供两层视图：

- 电网拓扑：母线、线路、变压器、发电机、逆变器和负荷。
- 动态设备内部结构：通过动态设备右键菜单中的“打开元件”，查看内部组件、状态、方程入口和运行参数。

展示器已接入本仓库中的 Julia/PowerSimulationsDynamics 后端。项目包含
`system.json` 时，可以编辑运行参数、配置求解器、运行或终止参数组仿真，并在成功结束后将
系统原始变量及所有适用的派生时间序列写入 SQLite；`compiled/network.bin` 只交给 Julia 后端校验和绑定，
源项目文件不会被直接改写。

## 安装

### macOS 独立安装包

Apple Silicon Mac（macOS 13 或更高版本）可以直接打开
`dist/PSD-GUI-macOS-arm64.dmg`，将 `PSD-GUI.app` 拖入“应用程序”后运行。
安装包内包含 Python、Qt、Julia 1.12.6、Julia 包环境以及本项目使用的
PowerSimulationsDynamics 源码，不要求宿主机预装 Python、Qt 或 Julia。

安装版只启动应用包 `Contents/Resources/julia` 中的 Julia，不读取 `PATH` 中的 Julia，
也不使用用户的 `~/.julia`。运行期生成的 Julia 编译缓存和历史记录写入本应用自己的
macOS 缓存目录，不会修改宿主机的 Julia 环境。首次启动后端时可能需要数分钟生成本机缓存，
后续启动会复用该缓存。

当前构建使用本地签名。如果没有 Apple Developer ID 证书和公证票据，复制到其他 Mac 后
首次启动可能需要在 Finder 中右键应用并选择“打开”。正式对外发布时，应使用 Developer ID
Application 证书签名并提交 Apple 公证。

在 Apple Silicon Mac 上重新构建安装包：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e . 'pyinstaller>=6.10,<7'
.venv/bin/python tools/build_macos.py
```

构建结果位于 `dist/PSD-GUI.app` 和 `dist/PSD-GUI-macOS-arm64.dmg`。

### 源码安装

需要 Python 3.11 或更高版本，以及可从 `PATH` 调用的 Julia 1.10 或更高版本。
Julia 后端的独立环境绑定本仓库中的修改版 `PowerSimulationsDynamics.jl`；首次点击“预编译”
可能需要数分钟，并可能由 Julia 下载尚未安装的依赖。建议为 Python 使用独立虚拟环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

## 启动

```bash
PowerSimulationDynamics-GUI
```

也可以运行：

```bash
python -m psid_graph_viewer
```

启动后点击“打开项目…”，选择包含下列文件的导出目录：

```text
manifest.toml
topology.toml
graph.toml
equations/index.toml
system.json            # 可选，用于显示运行参数
```

选中任意节点可在信息面板查看详情；右键动态发电机或逆变器并选择“打开元件”可进入内部组件视图。
搜索框支持名称、编号、类型、方程入口和状态名。macOS、Windows 和 Linux
触摸板均可使用双指手势平移画布；鼠标滚轮仍用于缩放，`Ctrl` 触摸板手势也保留给缩放。
支持双指张开放大、双指收缩缩小，并以手势所在位置为缩放中心。

节点可以直接拖动，连线会实时跟随。按住 `Ctrl`（Windows/Linux）或 `Cmd`（macOS）
单击可多选，拖动其中一个节点即可移动整组选区；`Ctrl/Cmd+Z` 和重做快捷键可撤销、
恢复位置变化。鼠标用户也可按住 `Space` 后左键拖动画布。“重置布局”会恢复自动分层布局。

单击或轻按拖动元件；双击元件后才会显示八个缩放控制点，避免移动和缩放互相干扰。
拖动边或角可改变元件大小，`Shift` 保持宽高比，
`Alt`（macOS 为 `Option`）从中心缩放，`Esc` 取消当前缩放。拖动时端口和连线实时更新，
松开后可整体撤销或重做；右键“重置大小”恢复元件默认尺寸。
这些位置变化只存在于当前会话，不会写入导出的项目文件。

右键单击元件可打开专用菜单：动态设备可使用“打开元件”进入下一层级，其他元件会显示为灰色；
具有官方方程实现的元件可使用“展示模型”，查看当前库实际采用的
`M(x) · ẋ = f(x, u)` 微分方程右端、代数/端口关系、方程入口和源码相对路径；复合设备会按
机器、控制器、轴系等子模型分段展示。没有收录模型的元件保持灰色，不会用猜测公式替代。
所有元件均可顺时针或逆时针旋转、左右镜像、上下镜像、重置方向、聚焦以及复制名称或组件路径。
顺时针旋转快捷键为 `Ctrl+R`（macOS 为 `Cmd+R`），逆时针旋转为
`Ctrl+Shift+R`（macOS 为 `Cmd+Shift+R`）；两个镜像操作不设快捷键。方向变换支持多选、撤销和重做，节点标题始终保持水平。

端口依据当前数据中的实际连接按需生成，不显示无连接的占位端口。进入设备内部层级后，
连接到外部母线的端口显示为空心边界端口；在其上悬停 1 秒可查看外部连接目标。
每条连线先沿端口所在边的法线向外引出固定短线，再进入曲线路径；旋转、镜像或缩放后
会按照端口的新边缘方向立即重绘，避免连线仍沿原方向出射。

总系统拓扑使用 `power_system_component_icons` 中的 SVG 单线图符号：母线、线路、两绕组
变压器、负荷、同步发电机、逆变器/交流电源和感应电机分别采用对应图标。注入设备优先按
动态类型匹配，避免把挂载在 `ThermalStandard` 上的动态逆变器显示成同步发电机；未知类型
使用空心通用节点。不可用元件保留同一电气符号并降低透明度。进入动态设备内部视图后，
设备根节点、控制逻辑和全部子模块均不显示图标，继续通过角色颜色和模型类型区分。

## 参数编辑与仿真

“参数”面板显示所选元件可安全作为运行参数处理的浮点字段；结构字段保持只读。
单个元件可直接编辑参数，同类型元件多选时显示公共参数并可批量赋值。参数修改支持
`Ctrl/Cmd+Z` 撤销和重做，只保存在当前会话的 `system.json` 工作副本中。

参数值也可以输入 `[1.1, 2.1]` 或 `range(a, b, c)` 创建参数扫描。`range` 在步长可达时
包含终点；多个扫描参数可在运行前选择“笛卡尔积”或“同步配对”，同步配对允许单值广播。
超过 100 个实例需要再次确认，单任务最多 10,000 个实例。同类型多选后输入数组时，所选元件
作为一个联动参数组，而不会彼此产生额外组合。

工具栏提供“预编译”“仿真设置”“运行仿真”和“终止仿真”：

- 预编译准备应用独立的 Julia 环境及 Residual/IDA、MassMatrix/Rodas 求解器。
- 仿真设置包含时间范围、模型形式、求解器、初始化、频率参考、采样间隔、步长和容差。
- 运行前确认任务名称、参数组合方式与实例数量；各实例在常驻 Julia 后端中顺序执行并复用计算图。
- 终止仿真通过求解器回调取消当前任务，后端正常情况下继续保持 `Ready`，且不会把
  `.partial` 文件当成完整结果；“停止后端”才会结束 Julia 进程。

Julia 后端随桌面应用启动并常驻，同一进程连续处理网络准备、仿真和导出任务，避免每次运行
重新加载 Julia 包和丢失首次调用 JIT 结果。窗口右下角使用绿色 `Ready`、红色 `Offline`、
黄色 `Busy` 同时显示颜色和文字状态；点击状态按钮可打开非模态“仿真后端管理”窗口，
查看 PID、Julia/PSID 版本、当前任务、项目与运行时指纹、计算图缓存来源和完整日志，也可
启动、停止或重启后端、预编译 Julia 环境、准备或重新构建当前网络以及终止当前任务。

计算图按“常驻进程内存 → 导出项目 → 应用缓存目录”的顺序复用。若导出项目的缓存因
PSID 方程源码、模型形式或网络结构变化而失效，首次准备会在 Qt 的跨平台应用缓存目录中
生成当前指纹对应的新计算图；后续运行直接命中缓存，不会修改导出项目。数值参数变化仍会
执行必要的参数绑定、潮流和初始条件计算，但不会使计算图失效。

工具栏“数据管理器”打开独立窗口。结果按“拓扑 → 仿真任务 → 仿真实例”管理，默认任务名为
“拓扑别名 · 时间”；每个实例保存完整参数快照、扫描变化、时间轴、全部信号、元数据和错误状态。
结果数据库默认位于系统应用数据目录，也可以在没有任务运行时更换。SQLite 使用事务和 WAL；
时间序列按压缩列保存，避免逐采样点记录造成大量数据库行。终止批量任务时，已完成实例仍会保留。

仿真结束不再直接输出到项目目录。需要文件时，在数据管理器中选择一个实例导出 CSV，或选择
整个任务把所有成功实例批量导出为 `case-0001.csv` 等文件。Julia 生成的内部临时文件在数据库
写入完成后自动清理。

## 面板布局

信息、参数和运行窗口均为可停靠面板，可以拖到主窗口左侧、右侧或底部，也可以浮动为独立窗口。
向已有面板的区域拖入另一个面板时会自动合并为标签栏。“视图”菜单可重新显示被关闭的面板，
也可恢复默认布局；面板位置、标签组合和主窗口尺寸会跨会话保存。后续新增窗口可以沿用相同的
停靠面板注册方式。

SQLite 中一次成功实例包含：

```text
任务记录              # 名称、时间、状态、设置、计算图指纹
├── 完整参数快照       # 压缩的 system.json
├── 本次扫描变化       # 用于快速比较的参数集合
├── 时间轴             # 压缩 Float64 数组
├── 全部结果信号       # 每个信号独立压缩，可按需读取
└── 元数据与错误状态
```

当导出项目中的 `compiled/network.bin` 与当前 PSID 源码指纹不一致时，后端会明确提示并从
当前系统重新构建网络图；数值参数修改不会写回原项目。

随应用发布的 `psid_graph_viewer/model_library.json` 是静态模型库，UI 只查询该文件，不在运行时
执行或解析 Julia。修改本仓库中的 PowerSimulationsDynamics 模型后，可在仓库根目录运行：

```bash
python tools/build_model_library.py
```

重新生成模型库。生成器提取 `mdl_*`、独立动态设备 `device!` 和输出限幅器入口中实际实现的
状态导数、质量矩阵非默认项、内部变量、电流端口及限幅关系。

## 自定义微分方程模型

打开项目后，启用工具栏中的“编辑模式”，再点击“自定义模型…”即可给尚未绑定动态模型的静态注入设备添加数据驱动模型。模型编辑器包含基本信息、端口、状态与方程、参数、网络输出和初始化六个页面。

- 状态方程写右端表达式，例如 `(-x + gain * v_r) / T`；质量系数单独填写，对应 `M · dx/dt = f(x,u)`。
- 网络接口必须定义 `i_r` 和 `i_i`，正值表示向网络注入。
- 可使用状态、参数以及 `t`、`v_r`、`v_i`、`omega_sys`、`P_ref`、`Q_ref`、`V_ref`、`omega_ref`、`system_base_power`、`device_base_power`。
- 表达式支持 `+ - * / ^` 和 `sin`、`cos`、`tan`、`asin`、`acos`、`atan`、`exp`、`log`、`sqrt`、`abs`、`min`、`max`、`clamp`。它不是任意 Julia 代码。
- 初始化可选择固定初值，或以所填初值为初猜求解 `f(x,u)=0`。

模型保存在项目内的 `.psid_gui/custom_models.json`，不会修改 PowerSimulationsDynamics 导出的 schema 1 文件。模型结构、状态顺序、方程、端口和质量系数会参与应用侧计算图缓存键；参数值仍可在不重新编译计算图的情况下修改。

## 画布结构编辑

打开项目后启用顶栏“编辑模式”，左侧组件栏会为“母线”“支路”和“注入设备”大类提供右键菜单“添加器件…”。模型管理器进入实例化选择状态后，选择官方整体模型或蓝色项目自定义整体器件，点击“实例化”，再在画布中单击完成放置。

浮动“绘图工具”栏提供选择、平移、连接、断开、删除、吸附网格、结构校验和保存。连接既可以从 Bus 开始，也可以从新增器件端口开始；从器件拖到 Bus 附近时只显示右侧一个自适应手柄，其输入/输出类型会根据当前拉线方向自动选择。完成连接后，临时手柄会被该连线专用的真实端口替代，离开连接模式后不保留空端口。选中新增器件与 Bus 之间的连线后，可用“断开”或 `X` 删除连接。Bus 支持无限连接，其他端口只允许一条连接。必需端口未连接或端口域不匹配时，校验会阻止准备计算图。

自定义整体器件在模型管理器中通过“新建自定义整体器件…”创建：先定义端口 ID、端口域、角色和必需性，再定义参数、状态及受限 Julia `equations!` 数学函数。当前 `AC_BUS` 是可连接到电网拓扑的端口域；`DC_BUS` 和 `SIGNAL` 会保存在模型中，但不能连接到 AC Bus。

进入动态发电机或动态逆变器内部后，对组件右键选择“替换内部模型…”。模型管理器只列出与当前槽位类别一致的官方模型和蓝色派生模型；替换后内部数据流按 PowerSimulationsDynamics 的 Machine/Shaft/AVR/TurbineGov/PSS 或 Converter/DCSource/FrequencyEstimator/OuterControl/InnerControl/Filter 端口合同自动布线。

选择或连接工具下均可沿 Bus 的四条边拖动真实端口；端口会吸附在边缘并自动维持最小间距，连接线随端口位置实时重绘。松开端口时只更新当前画布和布局文件，不重建整张图。端口位置与节点位置、大小、旋转、镜像一起保存在项目的 `.psid_gui/model.json`，导出的 TOML、`system.json` 和 `compiled/network.bin` 不会被改写。这些图形几何及运行参数值不参与计算图指纹；实例、所选整体模型、连接及端口参与结构指纹。

模型管理器只提供模型定义，不再把当前项目中的既有设备当作模板。选择 `StandardLoad`、`Source`、`DynamicGenerator` 或 `DynamicInverter` 后会创建具有独立 UUID 的新设备；其中动态设备由官方强类型配方装配 Machine、Shaft、AVR、Governor、PSS 或 Converter、OuterControl、InnerControl、DCSource、FrequencyEstimator、Filter。早期版本中保存的模板引用会在打开项目时移除并补齐模型库默认参数。放置到新的 Bus 后仍需提供物理上可行的潮流工作点；若控制器或限幅器初始化失败，后端会保留具体设备、状态和限值诊断。

新增的 `DynamicGenerator`、`DynamicInverter` 及项目自定义整体器件可以从节点右键菜单选择“打开元件”下钻。内部视图直接依据所选模型定义生成，不要求重新导出 `equations/index.toml`；左侧组件树同步列出内部组件和自定义状态，设备边界端口显示其在拓扑中连接的 Bus。

内部视图采用类似 Simulink 的端口信号显示：输入、输出圆点内侧标注 `δ,ω`、`τm`、`Vdc`、`Vcnv`、`v/i_filter` 等信号名，缩小时随 NodeGraphQt 代理模式自动隐藏。旋转或镜像组件后标签会跟随端口所在边缘重新排布并保持水平。橙色实线及圆形端口表示实际信号，灰色虚线及方形端口表示设备与子组件之间的层级关系。动态支路也可打开，并显示 `from V/I` 和 `to V/I` 两端边界信号。

新增 Bus、StandardLoad、Source、动态发电机和动态逆变器均会立即生成与 Julia 构造器一致的可编辑参数。旧版保存但缺少参数字段的实例会在打开项目时补齐；参数栏中的单值和参数组修改会保存到 `.psid_gui/model.json`，并在下一次构建或仿真时应用到实际 PowerSystems 组件。

自定义整体器件支持任意数量的 `AC_BUS` 端口。它在 Julia 后端中保持一份共享状态向量，从每个端口读取对应 Bus 电压，并把每个 `y.<port>_i_r/i_i` 注入相应 Bus 的 KCL，不会拆成多个伪设备。官方 `Line` 和 `Transformer2W` 可通过各自的起点、终点端口物化为真实支路。当前仍不物化删除已有器件和内部槽位替换；结构校验会明确阻止这些操作进入仿真。多端口整体模型暂不执行辅助函数，请将受限数学表达式直接写在 `equations!` 函数体中。

### 编辑快捷键

快捷键按照当前操作系统显示：macOS 使用 `Cmd`，Windows/Linux 使用 `Ctrl`。按 `F1` 可在应用内查看完整快捷键表。单字母、方向键和删除键只在画布获得焦点时生效，不会干扰搜索、参数或 Julia 代码输入。

- `V` 选择、`H` 平移、`W` 连接、`X` 断开、`A` 添加器件、`E` 调整大小，按住 `Space` 可临时平移，`Esc` 取消当前操作。
- `Cmd/Ctrl+R` 顺时针旋转，`Cmd/Ctrl+Shift+R` 逆时针旋转，`0` 重置方向，`Shift+0` 重置大小，镜像仍只通过右键菜单执行。
- `Enter` 打开选中元件，`M` 展示数学模型，`F` 聚焦选中元件，`Shift+F` 适应全部网络。
- 方向键移动 1 px，`Shift+方向键` 移动一个 20 px 网格；`+`、`-` 缩放，`1` 恢复 100% 缩放。
- `Cmd/Ctrl+O` 打开、`Cmd/Ctrl+S` 保存、`Cmd/Ctrl+Z` 撤销、平台原生重做键重做、`Cmd/Ctrl+F` 搜索、`F7` 校验。

## 模型管理器

项目打开后可随时点击工具栏“模型管理器…”浏览当前 PowerSimulationsDynamics 方程目录。左侧按照动态发电机、动态逆变器、独立动态设备和网络元件分层，中央显示官方模型及项目自定义模型，右侧显示方程入口、数学表达式、质量矩阵、源码路径和项目使用次数。

官方模型带锁图标并保持只读；项目自定义模型以及“＋ 添加自定义动态注入模型”使用蓝色并同时带有文字/图标标识。搜索支持模型名称、分类和方程入口，来源筛选可以只看官方模型或项目自定义模型。右键模型可以复制类型名、打开本地 Julia 源码，或在画布中定位其使用位置。

模型管理器在查看模式下始终可用。只有启用“编辑模式”后，才允许创建、修改、复制或删除项目自定义模型。完整的 `DynamicInjection` 可直接绑定运行；AVR、Machine、Filter 等内部组件可创建项目派生定义，并在复合组件替换器接入后装配运行。

### 继承官方模型

启用编辑模式后，每个官方组件分类底部都会显示蓝色“添加自定义…模型”，也可以右键某个官方模型选择“继承为自定义模型…”。派生模型继承并锁定官方模型的输入、状态和输出接口；编辑器中可以覆盖参数默认值，并使用受限 Julia 数学代码填写 `equations!(dx, y, x, u, p, t)` 的函数体或定义辅助函数。

- `x`/`dx` 是继承状态及其导数，`u` 是继承输入，`y` 是继承输出，`p` 是模型参数。
- 保存前会检查接口字段、必需输出、状态导数、括号和禁止的 Julia 功能。
- 模块加载、宏、文件/网络/进程操作、动态求值和全局状态修改不可用。
- 派生模型仅以蓝色显示在对应的官方模型分类中，不建立单独的派生模型分类。
- 派生定义随项目保存在 `.psid_gui/custom_models.json`，不修改 PowerSimulationsDynamics 的导出 TOML/JSON。

当前版本将派生组件保存为可复用的项目模型定义，但不会在没有复合组件替换器的情况下将 AVR、Machine、Filter 等叶组件冒充为完整动态注入设备。它们将在组件添加/替换功能中装配；原有独立 `DynamicInjection` 自定义模型仍可直接绑定和运行仿真。仅保存尚未装配的派生模型不会使当前计算图缓存失效。

## 组件面板

主窗口左侧的“组件”可停靠面板以文件树形式显示当前项目的母线、支路、注入设备及动态设备内部组件。面板可拖到左、右或底部，也可以浮动，拖入已有面板区域时会合并为标签页；“视图 → 组件”用于显示或隐藏，“重置面板布局”会将其恢复到左侧。

- 搜索支持名称、编号、类型、状态和组件路径，并保留匹配项的祖先层级。
- 可按全部、拓扑、动态、不可用和自定义组件过滤。
- 单击当前画布中的组件会同步选择画布并更新信息、参数面板；双击或按右键“打开并定位”会切换到正确层级并居中。
- “跟随画布”开启时，画布选择会自动展开并高亮树中的对应组件。
- 模型管理器右键“转到模型”会关闭模型管理器、打开组件面板，并在画布和组件树中同时高亮对应器件。
- 不可用组件显示为灰色，自定义组件实例显示为蓝色；尚未装配的模型定义仍只显示在模型管理器中。
